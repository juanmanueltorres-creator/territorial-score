# Territorial Score V0 acceptance

Date: 2026-08-30

This document defines the acceptance gate for Territorial Score V0. It is intentionally a verification record, not a product roadmap.

V0 is accepted only on a commit where the repository CI is green. A later change invalidates that acceptance until the same checks pass again on the new commit.

## Accepted scope

V0 is an evidence-first spatiotemporal context lab for RN150 / Corredor Agua Negra. It aligns independent terrain, weather, mobility, access and evidence tracks and can compare transparent rule candidates with optional Isolation Forest candidates.

`score` means score/partitura: independent tracks aligned in space and time. It does not mean an aggregate territorial risk number.

## Acceptance checklist

- [x] The public V0 semantics match `docs/specs/v0.md`: signal is not conclusion, missing is not zero, modelled is not observed, simulation is not operation, and anomaly candidate is not road defect.
- [x] Corridor and terrain lineage are documented in `docs/data-sources.md`; the overview corridor is explicitly non-navigation geometry.
- [x] Access remains `PENDING` when no official operational state exists; no code path coerces missing/PENDING context into open, safe or zero.
- [x] Checked-in JSON enters the application through strict runtime validation before reaching the typed domain/core boundary.
- [x] Core corridor, terrain, weather, access and evidence artifacts are required by the dataset loader; optional mobility/candidate artifacts remain removable without breaking the core.
- [x] Artifact paths are constrained to safe relative paths inside the dataset root.
- [x] The transparent rule detector is deterministic and its checked-in candidate artifact is regenerated and compared byte-for-byte in CI.
- [x] The synthetic mobility benchmark and synthetic ground-truth artifact are deterministic and regenerated byte-for-byte in CI.
- [x] Isolation Forest V0.1 is deterministic under the documented configuration and its checked-in candidate artifact is regenerated byte-for-byte in CI.
- [x] Rule and ML outputs share the same auditable mobility-candidate contract.
- [x] The UI can distinguish `RULE CANDIDATE`, `ML CANDIDATE` and `BOTH` for the selected segment and candidate time window.
- [x] Candidate UI remains labelled `SYNTHETIC EXPERIMENT` and states `Anomaly candidate ≠ road defect. Requires contextual review.`
- [x] Synthetic ground truth is reserved for offline evaluation and is not rendered as observed truth in the normal application UI.
- [x] The model card reports the benchmark result without converting anomaly score into probability, confidence, severity or operational risk.
- [x] The production TypeScript build succeeds under the repository CI gate.
- [x] The Python benchmark/test suite succeeds under the repository CI gate.
- [x] The README explicitly states the principal non-goals and links the canonical V0 documentation.
- [x] Future GeoPlatform integration is bounded by `docs/geoplatform-adapter-boundary.md` and is not implemented in V0.

## Canonical verification gate

The GitHub Actions workflow in `.github/workflows/ci.yml` is the canonical acceptance gate for a commit. It runs two independent jobs.

### TypeScript / application

```bash
npm install --no-audit --no-fund
npm test
npm run build:rule-candidates -- \
  public/data/agua-negra-v0/mobility.synthetic.json \
  /tmp/candidates.rule.json
cmp /tmp/candidates.rule.json public/data/agua-negra-v0/candidates.rule.json
npm run build
```

The current integration suite covers the application flow, including the spatiotemporal candidate comparison and the separation between runtime UI and synthetic ground truth.

### Synthetic mobility experiment

```bash
python -m pip install -e "experiments/mobility-anomaly[dev]"
python -m pytest experiments/mobility-anomaly/tests -q

python experiments/mobility-anomaly/scripts/build_benchmark.py \
  --seed territorial-score:agua-negra:mobility:v0.1 \
  --mobility-output /tmp/mobility.synthetic.json \
  --truth-output /tmp/anomaly-ground-truth.synthetic.json
cmp /tmp/mobility.synthetic.json public/data/agua-negra-v0/mobility.synthetic.json
cmp /tmp/anomaly-ground-truth.synthetic.json public/data/agua-negra-v0/anomaly-ground-truth.synthetic.json

python experiments/mobility-anomaly/scripts/train_and_export.py \
  --input public/data/agua-negra-v0/mobility.synthetic.json \
  --output /tmp/candidates.ml.json
cmp /tmp/candidates.ml.json public/data/agua-negra-v0/candidates.ml.json

python experiments/mobility-anomaly/scripts/evaluate_artifacts.py \
  --ground-truth public/data/agua-negra-v0/anomaly-ground-truth.synthetic.json \
  --rule-candidates public/data/agua-negra-v0/candidates.rule.json \
  --ml-candidates public/data/agua-negra-v0/candidates.ml.json
```

## Benchmark evidence

The canonical V0.1 model card records:

| Detector | Precision | Recall | F1 | TP | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Transparent rule | 1.00 | 0.25 | 0.40 | 1 | 0 | 3 |
| Isolation Forest V0.1 | 0.50 | 0.50 | 0.50 | 2 | 2 | 2 |

This supports only the narrow conclusion that Isolation Forest adds candidate detection on this deterministic synthetic benchmark. It does not establish real-world generalization or operational usefulness.

## Explicit V0 non-goals

Territorial Score V0 is not:

- live telemetry;
- road status;
- navigation;
- mine dispatch;
- a safety system;
- a real road-defect detector;
- a global or aggregate risk score.

No V0 acceptance result authorizes changing those boundaries.
