# Territorial Score V0

Territorial Score is an evidence-first spatiotemporal context engine. In this project, **score means musical score / partitura, not a synthetic risk score**.

## V0 case

RN150 / Corredor Agua Negra, San Juan, Argentina.

V0 aligns independent territorial tracks without turning them into an operational decision:

- terrain;
- weather;
- mobility;
- access;
- evidence;
- optional ML anomaly candidates.

## Integrity rules

```text
signal != conclusion
correlation != causality
missing != zero
modelled != observed
simulation != operation
anomaly candidate != road defect
human signal != official instruction
```

Weather is `MODELLED` in V0. Mobility is `SIMULATED`. ML candidates are `SYNTHETIC_EXPERIMENT` only.

No public contract may claim or encode route safety, transitability, authorization, a road defect, or an aggregate risk score.

## Runtime boundary

```text
untrusted/static artifact
        ↓
strict runtime validation
        ↓
typed domain object
        ↓
core
```

Every checked-in JSON artifact must validate before entering the core.

## Machine-learning boundary

ML is optional and auditable. The first planned experiment compares a simple rule baseline with Isolation Forest over a versioned synthetic mobility benchmark. Terrain, weather, access and evidence remain independent context and are not V0.1 ML input features.

Removing the ML artifact or experiment must not break the Territorial Score core.
