# Territorial Score V0.2 — Public Understanding + Satellite Context Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a self-explanatory Territorial Score V0.2 for non-specialists, with a frozen deterministic Sentinel-2 context artifact, human-readable corridor UX, and the existing mobility ML experiment clearly separated from territorial evidence.

**Architecture:** Keep V0.1 immutable. Add a new self-contained `agua-negra-v0.2` snapshot, a strict dedicated satellite artifact, and a deterministic builder fed only by a checked-in frozen source snapshot. The browser loads versioned local artifacts only; GeoPlatform/GEE is acquisition-time input, never a runtime dependency. UI consumes only the typed `TerritorialDataset` boundary.

**Tech Stack:** Node 22, React 19, TypeScript 5.8, Vite 7, Zod 4, MapLibre GL 5.7, Vitest 3, Testing Library, existing Python 3.12 / scikit-learn 1.9 mobility experiment.

**Spec:** `docs/superpowers/specs/2026-08-30-v0.2-public-understanding-and-satellite-context-design.md`

## Global Constraints

- Primary audience: a non-specialist opening the public URL with no prior explanation.
- `score` means musical score / partitura, never aggregate risk.
- Preserve: `missing != zero`, `modelled != observed`, `simulation != operation`, `candidate != defect`, `PENDING != open/closed/safe`.
- Add: `satellite signal != road condition`, `snow-like != snow on road`, `snow-like != road closed`, `cloudy/missing != clear`, `derived != observed in field`.
- No Random Forest, satellite ML classifier, live GEE calls, live GeoPlatform dependency, live telemetry, WHAT_IF, optimization, safety score, road-status inference, or write-back.
- `public/data/agua-negra-v0/` must remain byte-unchanged.
- V0.2 lives in `public/data/agua-negra-v0.2/` with manifest `schemaVersion: "0.2"` and `datasetId: "agua-negra-v0.2"`.
- `MISSING` is availability/absence, not an `EvidenceState`.
- Satellite `AVAILABLE` requires finite NDVI/NDWI/NDSI, deterministic class, `evidenceState: "DERIVED"`, and a local preview reference.
- Satellite `MISSING` requires `indices: null`, `surfaceClass: null`, `evidenceState: null`, `previewRef: null`, and a declared missing reason.
- CI never calls external satellite services. It regenerates `satellite-context.json` and `satellite-preview.svg` only from the checked-in frozen source snapshot and byte-compares both outputs.
- Existing mobility benchmark generation, rule artifact check, ML artifact check, evaluation, Node tests, Python tests, TypeScript build, and Vercel deployment remain release gates.

```ts
export function classifySurface(indices: SpectralIndices): SatelliteSurfaceClass {
  if (indices.ndsi >= 0.40 && indices.ndvi < 0.20) return "SNOW_LIKE";
  if (indices.ndwi >= 0.30 && indices.ndsi < 0.40) return "WATER_LIKE";
  if (indices.ndvi >= 0.30) return "VEGETATION";
  if (indices.ndvi < 0.30 && indices.ndwi < 0.30 && indices.ndsi < 0.40) return "BARE_GROUND_LIKE";
  return "UNCLASSIFIED";
}
```
