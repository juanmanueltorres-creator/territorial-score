# Territorial Score V0.2 — Public Understanding + Satellite Context Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a self-explanatory Territorial Score V0.2 for non-specialists, with a frozen deterministic Sentinel-2 context artifact, human-readable corridor UX, and the existing mobility ML experiment clearly separated from territorial evidence.

**Architecture:** V0.1 remains immutable. V0.2 adds a new `agua-negra-v0.2` dataset and manifest schema, a dedicated strict `SatelliteContextArtifact`, and a deterministic classification builder that consumes a frozen raw satellite source snapshot. The browser loads only checked-in versioned artifacts; it never calls GeoPlatform or GEE at runtime. UI changes are layered on top of the same validated `TerritorialDataset` boundary.

**Tech Stack:** Node 22, React 19, TypeScript 5.8, Vite 7, Zod 4, MapLibre GL 5.7, Vitest 3, Testing Library, existing Python 3.12 / scikit-learn 1.9 mobility experiment.

**Spec:** `docs/superpowers/specs/2026-08-30-v0.2-public-understanding-and-satellite-context-design.md`

## Global Constraints

- Primary audience is a non-specialist opening the public URL with no prior explanation.
- `score` means musical score / partitura, never aggregate risk.
- Preserve: `missing != zero`, `modelled != observed`, `simulation != operation`, `candidate != defect`, `PENDING != open/closed/safe`.
- Add and preserve: `satellite signal != road condition`, `snow-like != snow on road`, `snow-like != road closed`, `cloudy/missing != clear`, `derived != observed in field`.
- No Random Forest, satellite ML classifier, live GEE calls, live GeoPlatform dependency, live telemetry, WHAT_IF, optimization, safety score, road status inference, or write-back.
- V0/V0.1 checked-in artifacts remain unchanged under `public/data/agua-negra-v0/`.
- V0.2 uses a new checked-in directory: `public/data/agua-negra-v0.2/` and manifest `schemaVersion: "0.2"`.
- `MISSING` is availability/absence, not a new `EvidenceState`.
- A V0.2 satellite segment with `availability: "AVAILABLE"` must have finite indices, a deterministic surface class, and `evidenceState: "DERIVED"`.
- A V0.2 satellite segment with `availability: "MISSING"` must have `indices: null`, `surfaceClass: null`, `evidenceState: null`, `previewRef: null`, and a declared missing reason.
- CI must not call external satellite services. It regenerates `satellite-context.json` only from a checked-in frozen raw source snapshot and byte-compares the output.
- Existing mobility benchmark generation, rule artifact checks, ML artifact checks, evaluation, Node tests, Python tests, TypeScript build, and Vercel deployment remain release gates.

These are spectral-context rules only; they are not field truth.

```ts
export function classifySurface(indices: SpectralIndices): SatelliteSurfaceClass {
  if (indices.ndsi >= 0.40 && indices.ndvi < 0.20) return "SNOW_LIKE";
  if (indices.ndwi >= 0.30 && indices.ndsi < 0.40) return "WATER_LIKE";
  if (indices.ndvi >= 0.30) return "VEGETATION";
  if (indices.ndvi < 0.30 && indices.ndwi < 0.30 && indices.ndsi < 0.40) return "BARE_GROUND_LIKE";
  return "UNCLASSIFIED";
}
```
